# PATHMIND — College Engineering MVP Documentation Pack

This documentation pack contains:

1. `PRD_PATHMIND_COLLEGE_MVP.md` — product requirements, learner journey, scope, adoption metrics and non-goals.
2. `TRD_PATHMIND_COLLEGE_MVP.md` — technical architecture, agent design, source verification, memory, accountability, APIs, security and testing.
3. `DATABASE_SCHEMA_PATHMIND_COLLEGE_MVP.md` — Firestore collections, document schemas, memory model, academic knowledge model and security boundaries.

## MVP scope

Supported deep-learning paths:

- Mechanical Engineer
- Electrical Engineer
- Computer Science / Software Engineer
- AI Engineer
- Civil Engineer

The platform remains capable of responding to other aspirations with a lighter/general learning path rather than rejecting them.

## Product flow

```text
LOGIN
  ↓
IDENTITY
  ↓
UNIVERSITY + ENGINEERING COURSE
  ↓
SEMESTER / SUBJECT / GOAL
  ↓
LEARNER EVIDENCE + ASSESSMENT
  ↓
STRENGTHS / WEAKNESSES / BASELINE
  ↓
UNIVERSITY-SPECIFIC VERIFIED SOURCES
  ↓
ORDERED LEARNING PLAN
  ↓
PRACTICE + PYQs
  ↓
ASSESSMENT
  ↓
MASTERY / REINFORCEMENT
  ↓
ACCOUNTABILITY
  ↓
MEMORY
  ↓
ADAPTATION
```

The existing PATHMIND visual language remains unchanged. The login design supplied by the product owner becomes the first screen of the learner journey.
